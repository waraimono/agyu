# あーぎゅ

議論そのものを中心にしたSNSを目指して開発している個人プロジェクトです。

現在のSNSでは、意見を投稿したり反応したりすることは簡単ですが、
異なる意見を持つ人同士が継続して議論し、その過程や結果を残すことには
あまり特化していません。

「あーぎゅ」では、

**問い → 議論 → 考えの変化 → 結果 → 新しい問い**

という流れをSNS上で表現することを目指しています。

> 現在開発中のため、仕様・UI・機能は変更される可能性があります。

---

## 基本的な使い方

すべてのユーザーが、議論に対して主に3つの関わり方を持ちます。

### 議論を投稿する

自分で議題を提示し、新しい議論を作成します。

### 議論に参加する

他のユーザーが作成した議論に参加し、
議論の当事者として発言します。

### 議論を見る

他のユーザー同士の議論を閲覧します。

議論に参加していないユーザーは「外野」として、
議論本体とは別の領域にコメントすることもできます。

## 現在実装されている主な機能

- 議論の作成
- 議論への参加申請・承認
- 2人を中心とした議論
- リアルタイムメッセージ
- 議論の閲覧
- 外野コメント
- 議論画面への入退室

2026年10月2日に一般アカウント2つを使用して、
基本的な議論フローの動作確認を行っています。

## 今後実現したいこと

議論を単なるチャットで終わらせず、

- 議論前後の立場の変化
- 議論結果
- 合意した部分・対立した部分
- 議論から派生した新しい問い
- 議論同士の関係

などを残せる仕組みを検討しています。
